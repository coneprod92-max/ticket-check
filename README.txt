TICKETCHECK
===========

Fichiers : index.html, formulaire.html, admin.html, style.css, config.js, formulaire.js, admin.js.

Installation : importer les fichiers dans le dépôt GitHub, puis activer GitHub Pages sur main / root.

Administration : créer dans Supabase Authentication > Users le compte coneprod92@gmail.com avec un mot de passe fort. Puis ouvrir /admin.html.

Sécurité : le site ne demande pas le PIN/code secret complet d'un ticket. Ne jamais mettre une clé service_role/secret dans config.js.
